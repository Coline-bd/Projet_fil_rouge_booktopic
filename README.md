BookTopic est un projet de réseau social dédié aux livres et à la lecture.
L'objectif est de permettre aux utilisateurs de découvrir des livres, de consulter leurs informations et, à terme, de partager leurs avis et leurs expériences de lecture avec une communauté.

Projet actuellement en développement.

Fonctionnalités prévues : 
-Recherche de livres
-Affichage des informations principales d'un livre
-Page détaillée pour chaque livre
-Recherche par catégorie
-Création d'un compte utilisateur
-Connexion / déconnexion
-Publication d'avis sur les livres
-Attribution d'une note
-Ajout de livres aux favoris
-Création d'une liste de lecture
-Suivi d'autres utilisateurs
-Fil d'actualité
-Commentaires
-Système de recommandations

Technologies
Le projet est actuellement développé avec :
-HTML5 — structure et sémantique
-CSS — gestion des styles
-JavaScript — logique et interactions
-Vite — environnement de développement et build
-API google books — récupération des données bibliographiques
-Git / GitHub — gestion du code source et versionnement

BookTopic utilise actuellement l'API Google Books pour récupérer les informations relatives aux livres.
Les données utilisées peuvent notamment inclure :
-titre
-auteur
-couverture
-année de publication
-langue
-catégories

Le site est développé selon une approche Mobile First. L'interface est donc pensée en priorité pour les petits écrans avant d'être adaptée aux :
smartphones
-tablettes
-ordinateurs
Une attention particulière est portée à l'accessibilité et à la sémantique HTML.

Git Workflow
Le développement du projet est organisé avec Git.
Les fonctionnalités sont développées sur des branches dédiées avant d'être intégrées à la branche dev.
exemple : feature/cardBook
